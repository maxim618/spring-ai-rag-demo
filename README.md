# Spring AI RAG Demo

A learning demo project to explore the capabilities of Spring AI 2.0 and implement RAG (Retrieval-Augmented Generation) architecture.

# Tech Stack

* Java: 21
* Spring Boot: 4.1.0
* Spring AI: 2.0.0
* LLM API: OpenAI-compatible interface (configured for OpenRouter)
* Maven
