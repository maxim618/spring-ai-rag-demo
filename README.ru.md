Учебный проект для изучения Spring AI 2.0 с
Retrieval-Augmented Generation (RAG).

Проект развивается постепенно: от базовой интеграции с LLM к RAG-конвейеру,
который сможет формировать релевантные ответы на вопросы.

## Практический сценарий

В качестве целевого сценария рассматривается компания по доставке еды.

Перед началом смены курьеры проходят check-list для повторения стандартов доставки.

Ассистент предназначен для ответов на вопросы, связанные со стандартами доставки.

Предполагается, что ассистент сможет:

- находить релевантные части стандартов доставки;
- отвечать на вопросы курьера, используя найденный контекст;
- объяснять применимый стандарт в конкретной ситуации.

## Почему RAG?

Обычная LLM может не располагать необходимыми предметно-специфическими знаниями.

RAG позволяет использовать релевантный контекст при формировании ответа,
сохраняя при этом естественный формат взаимодействия с LLM.

## Текущий статус

Проект находится на ранней стадии разработки.

Реализовано:

- базовое приложение на Spring Boot;
- интеграция со Spring AI;
- настройка `ChatClient`;
- интеграция с OpenAI-совместимым API;
- простой chat endpoint.

Планируется:

- загрузка документов (Document Ingestion);
- разбиение документов на части (Document Chunking);
- генерация эмбеддингов (Embeddings);
- подключение векторного хранилища (Vector Store);
- поиск релевантных документов (Retrieval);
- дополнение prompt на основе найденного контекста;
- подготовка материалов со стандартами доставки;
- сборка сквозного RAG-конвейера;
- тесты компонентов RAG.

## Архитектура

Целевой RAG workflow:

```text
Материалы
       │
       ▼
Загрузка документов
       │
       ▼
Разбиение документов
       │
       ▼
   Embeddings
       │
       ▼
Векторное хранилище
       │
       │ релевантный контекст
       ▼
Вопрос курьера
       │
       ▼
    Retrieval
       │
       ▼
Релевантный контекст
       │
       ▼
      LLM
       │
       ▼
     Ответ
```

На текущем этапе компоненты retrieval и vector store ещё не реализованы.

## Конфигурация

Приложение использует OpenAI-интеграцию Spring AI и может работать с
OpenAI-совместимым API.

API-ключи должны передаваться через переменные окружения и не должны храниться
в репозитории.

Настройки провайдера и модели находятся в `application.properties`.
