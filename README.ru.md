# Spring AI RAG Demo

Учебный демо-проект для изучения возможностей Spring AI 2.0 и реализации архитектуры RAG (Retrieval-Augmented Generation).

# Стек технологий

* Java: 21
* Spring Boot: 4.1.0
* Spring AI: 2.0.0
* LLM API: OpenAI-совместимый интерфейс (настроен под OpenRouter)
* Maven
